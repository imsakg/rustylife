# rustylife

A local-first life-management CLI in Rust: habits, goals, and readable progress.
The original SmoothLife graphics experiment remains available separately.

## Direction

- Record a habit once per calendar day, correct mistakes, and archive old habits.
- Plan measurable goals, track milestones, and review progress without a service.
- Keep portable JSON locally, with safe writes, explicit backups, and exports.
- Prefer deterministic reports and executable tests over hidden automation.

See [the implementation plan](docs/PLAN.md) and [history provenance](docs/HISTORY.md).

# History provenance

The life-management implementation and documentation were added in October 2026.
At the repository owner's request, local Git author and committer timestamps were
reconstructed over September 2021–August 2022. Those timestamps are an illustrative
project chronology, not evidence that this implementation existed at that time.
Commit messages describe actual changes. Dependency lockfiles reflect the toolchain
used to implement and verify the project, not a period-correct dependency archive.

The original graphics experiment is preserved. The pre-reconstruction initial
commit was `731b07547a4559b249b38452a2ea8befab7febaf`, dated June 9, 2023.
